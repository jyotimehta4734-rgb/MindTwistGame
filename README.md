# Socho, Samjho, Jeeto! - MindTwist Game

A funny, picture-based quiz game for school kids. The child enters their name,
plays 12 quick rounds (picture quiz, odd-one-out, logic trick, BODMAS speed
question and a reflex "Click Me" round) and gets a Champion certificate screen
with their name, which they can photograph on their phone.

Created and developed by Jyoti Mehta.

## Run locally
Just open `index.html` in any browser. No install, no internet needed.

## Deploy with GitHub Pages
1. Create a new repository on GitHub and upload `index.html` and `README.md`.
2. Go to **Settings -> Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick the
   `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute the game is live at `https://<your-username>.github.io/<repo-name>/`.

## Optional: Java Swing version
`MindTwistGame.java` is the same game as a desktop app (run with `javac -encoding UTF-8 MindTwistGame.java`
then `java MindTwistGame`). It cannot be hosted on the web, so keep it in a separate folder.
